# GTA VI Daily Report

Automated daily news site covering the latest **GTA VI** news, leaks, and community highlights. Reports are generated automatically every day using the Claude API and published via Vercel.

## Features

- Daily reports auto-generated by AI (Claude) with real web search (Tavily)
- Posts written in Markdown and published automatically via GitHub Actions
- Dark-themed UI built with Next.js + Tailwind CSS
- Analytics powered by Vercel Analytics
- Deploys automatically on every push via Vercel

## Tech Stack

| Layer | Technology |
|---|---|
| Framework | Next.js 16 (App Router) |
| Styling | Tailwind CSS |
| Content | Markdown files with gray-matter + remark |
| AI | Claude API (claude-sonnet-4-6) |
| Web Search | Tavily API |
| Automation | GitHub Actions (daily cron) |
| Hosting | Vercel |
| Analytics | Vercel Analytics |

```
│   └── posts.ts             # Reads and parses Markdown posts
├── posts/
│   └── YYYY-MM-DD.md        # One file per daily report
├── scripts/
│   └── generate_report.py   # AI report generation script
└── .github/workflows/
    └── daily-report.yml     # GitHub Action (runs daily at 10 AM BRT)
```

## How It Works

1. Every day at **10:00 AM (Brasília time)**, a GitHub Action triggers automatically
2. The script searches the web for the latest GTA VI news using Tavily
3. Results are sent to Claude, which generates a structured Markdown report
4. The report is committed to the `posts/` folder as `YYYY-MM-DD.md`
5. Vercel detects the push and deploys the updated site within minutes

## Publishing a Report Manually

**Via GitHub UI** (no code needed):
1. Go to [Actions → GTA VI Daily Report](https://github.com/carlosrcoelho/gta6-news/actions/workflows/daily-report.yml)
2. Click **Run workflow**

**Via CLI:**
```bash
export ANTHROPIC_API_KEY=your_key
export TAVILY_API_KEY=your_key
python scripts/generate_report.py
```

## Adding a Report Manually

Create a new file in `posts/` following this format:

```markdown
---
title: "GTA VI Daily Report — April 28, 2026"
date: "2026-04-28"
excerpt: "One-line summary of today's highlights."
---

## Official News
...

## Leaks & Rumors
...

## Community Highlights
...

## Sources
...
```

## Required Secrets

Set these in [GitHub Settings → Secrets → Actions](https://github.com/carlosrcoelho/gta6-news/settings/secrets/actions):

| Secret | Description |
|---|---|
| `ANTHROPIC_API_KEY` | Claude API key from [console.anthropic.com](https://console.anthropic.com) |
| `TAVILY_API_KEY` | Web search API key from [app.tavily.com](https://app.tavily.com) |
